    Customer

    Add a computer by hand

    For a computer that didn't register itself — a plain RustDesk, a server, or one you set up manually.

    1. On that computer, open its RustDesk / exSupport app and note the ID (9 digits) shown on the main screen.
    2. Set a fixed password there (Settings → Security → "Set permanent password") so you can connect any time.
    3. Type the ID and password below. Leave the password empty to be asked for it on each connection.
